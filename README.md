# imgenfeedback

Локальный веб-интерфейс для разбора результатов генерации изображений: сетка
последних картинок, поле фидбека под каждой и технический провенанс, подтянутый
из манифестов.

Сделан для работы с `comfyui-remote` (генерация SDXL-картинок через ComfyUI),
но работает с любой папкой, где лежат PNG + jsonl-манифесты рядом с ними.

## Возможности

- **Сетка последних картинок** с фильтрами: префикс серии, поиск по имени, «только с фидбеком»
- **Поле фидбека** под каждой картинкой → сохраняется в `data/feedback.jsonl` (append-only)
- **Провенанс** из манифестов: модель, LoRA с силами, cfg, steps, seed, сэмплер, промпт, негатив
- **Клик по картинке** — увеличение
- Имена файлов проверяются регулярным выражением (нет path traversal)

## Требования

- Python 3.10+
- Flask

## Установка

```bash
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
```

## Запуск

```bash
./venv/bin/python app.py
```

Откроется на `http://0.0.0.0:8899` — заходи с любого устройства в той же сети
по IP машины (`hostname -I`).

### Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `IMGF_IMG_DIR` | `/home/art/projects/image_gen_2026_oct/outputs` | папка с картинками и манифестами |
| `IMGF_FEEDBACK` | `data/feedback.jsonl` рядом с `app.py` | файл с фидбеком |
| `IMGF_PORT` | `8899` | порт |

```bash
IMGF_IMG_DIR=/path/to/outputs IMGF_PORT=9000 ./venv/bin/python app.py
```

Если хочешь, чтобы фидбек сразу попадал в git-репозиторий (например, в приватный
репозиторий с проектом), укажи путь к файлу — папка создастся сама:

```bash
IMGF_FEEDBACK=/home/art/projects/image_gen_2026_oct/feedback/feedback.jsonl \
  ./venv/bin/python app.py
```

## Формат манифеста

Провенанс подтягивается из любых `*.jsonl` в папке с картинками. Одна JSON-запись
на кадр, ключ `file` содержит имя файла:

```json
{"file":"example_797721866.png","model":"photorealisticAllPurpose_v40.safetensors",
 "loras":[["Nynx_Realistic_SDXL_v1.0_LoRA.safetensors",0.8,0.9]],
 "sampler":"dpmpp_2m","scheduler":"karras","cfg":3.5,"steps":30,
 "w":832,"h":1216,"seed":797721866,"prompt":"...","negative":"..."}
```

Любые отсутствующие поля просто не показываются — работает и без манифестов.

## Формат фидбека

`data/feedback.jsonl`, по записи на сохранение:

```json
{"file":"example_797721866.png","text":"свет хороший, кожа живая","ts":"2026-10-02T14:09:05"}
```

## Фоновый запуск (Linux)

```bash
setsid nohup ./venv/bin/python app.py > /tmp/imgenfeedback.log 2>&1 < /dev/null &
```

`setsid` обязателен — без него процесс умирает вместе с шеллом.
